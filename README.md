# Chrono Luxe

Build a complete, high-end, multi-page e-commerce website for a premium watch brand.

DESIGN:

- Use a dark, premium and modern theme.

- Main colors: near-black/dark charcoal background, white text, with elegant gold/champagne accents.

- Make the design look luxurious, clean and professional, not flashy or overcrowded.

- Use smooth animations and transitions throughout the website.

- Add subtle hover effects, scroll animations, glass/gradient effects where appropriate.

- Make the website fully responsive for desktop, tablet and mobile.

- Use high-quality watch/product imagery placeholders that can later be replaced with real product images.

- Use attractive cards, sections, badges, icons and interactive UI elements.

- Keep typography elegant and highly readable.

HOME PAGE:

Create a premium hero section with a strong headline, short description and Shop Now button.

Include:

- New arrivals

- Discount products

- Product categories

- Limited-time offer section

- Why choose us

- Customer reviews

- Footer with all important links

SHOP:

Each product card should show:

- Product image

- Product name

- Brand

- Price

- Original price when discounted

- Discount percentage

- Availability/stock status

- Rating

- Add to Cart button

- Wishlist button

Add:

- Search bar

- Price filter

- Brand filter

- Gender filter

- Strap/material filter

- Sort by price, newest, popularity and rating

- Pagination or load more

PAYMENT:

Create the payment system structure, but DO NOT store customers' card numbers, CVV, passwords, bank credentials or other sensitive payment information in our database.

Initially use a safe test/mock payment flow so the website can be demonstrated.

Structure the system so a real payment gateway can be integrated later.

DISCOUNTS:

Create a discount management system:

DATABASE:

Use a proper database structure for:

- Users

- Products

- Categories

- Product variants

- Inventory

- Orders

- Order items

- Customers

- Discounts/coupons

- Reviews

- Wishlist

- Payment transaction references

SECURITY:

- Use authentication for customer and admin accounts.

- Protect admin pages.

- Customers must not be able to access admin functions.

- Never store passwords or sensitive payment credentials as plain text.

- Use secure authentication and database access rules.

IMPORTANT:

- Build this as a real functional e-commerce application, not just a visual mockup.

- Use reusable components.

- Keep the code organized and maintainable.

- Do not remove existing functionality when adding new features.

- Make all buttons and navigation links functional.

- Use realistic sample watch products so the website looks complete.

- Make the UI polished and production-ready.

- Before making major architectural changes, explain what you plan to change.
